🚀 JobTrackPro

Professional Job Application Tracking System

✅ Project Status: Ready to Run

Full-stack application with authentication, database integration, and modern UI

Quick Start

  1. Install dependencies: npm install (backend) and cd frontend && npm install
  2. Configure database in .env file (copy from .env.example)
  3. Start backend: npm start
  4. Start frontend: cd frontend && npm run dev
  5. Open Frontend App and API Docs
